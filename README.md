# Mezo Gift Challenge

برنامج تحدي الهدايا لبث تيك توك لايف — ملف exe واحد، مش محتاج تثبيت.

## التحميل

حمّل **`Mezo Gift Challenge.exe`** من هنا أو من صفحة [Releases](../../releases/latest) وشغّله مباشرة.

> أول مرة ممكن ويندوز يظهر "Windows protected your PC" لأن البرنامج مش موقّع: اضغط **More info** ثم **Run anyway**.

## الاستخدام

1. افتح البرنامج واكتب اسم حساب تيك توك واضغط **اتصال**.
2. **والبرنامج مفتوح**، اضغط **نسخ الرابط** وحطه في TikTok LIVE Studio (مصدر Link) أو OBS (Browser Source):
   ```
   http://127.0.0.1:3030/cards-overlay.html
   ```
   لايف ستوديو بيجرب يفتح الرابط وقت ما تحطه، فلو البرنامج مقفول هيقولك "أدخل عنوان URL الصحيح".
3. اختار هدايا كل فريق، وابدأ التحدي.

خلي البرنامج مفتوح (حتى لو متصغر) طول البث.

## الاختصارات

| الاختصار | الوظيفة |
|---|---|
| `Alt + F11` | إخفاء التحدي / ضغطة تانية تظهره كتحدي جديد من الصفر |
| `Alt + F12` | تشغيل التايمر من 50 ثانية / ضغطة تانية توقفه |

الاختصارات بتشتغل من أي مكان في ويندوز، وتقدر تغيرها من البرنامج.
